# Luma Imai Interface Details

Align labels, fields, hints and actions to the same edges. Use tabular numbers for changing values and normal tracking for non-Latin scripts. Balance actions with useful context, not decorative chips. Keep the actual hit area large even when an icon is small. Do not add shadows, new radii or pills merely because another app uses them.

Use short interruptible color/opacity transitions for control feedback. Avoid animating whole forms on every validation update. Respect reduced motion. Inspect real text wrapping, images and focus rings in the browser before claiming visual completion.

Source: `.agents/skills/make-interfaces-feel-better/SKILL.md` in imai-dev. Luma's tokens override its generic radius, shadow and stagger suggestions.
