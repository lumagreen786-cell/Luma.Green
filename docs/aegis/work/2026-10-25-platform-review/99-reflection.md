# Review lesson

Test language changes with two tabs and a production build. A shared cookie can change another tab's route. A production client cache can also skip a redirect that appeared reliable in development. The repair keeps the URL as the language owner and resolves the canonical target in one shared router. Tests retain both failure cases.

State and access must have the same lifetime: API secrets belong to a workspace, file bytes belong to their saved record, a provider result belongs to the device binding that sent it, and payment review holds survive unrelated cancellation evidence. The new regressions test those boundaries.
