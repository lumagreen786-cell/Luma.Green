## Approval record to use later

For each selected proposal, record the user problem and baseline, the exact
provider/product, fields sent and retained, where credentials live, quotas,
expected monthly volume and hard spend limit, failure/manual path, account owner,
retention and deletion steps. List tests, required browser views and received
provider evidence. Then update the owning specification before implementation.
A useful API is not evidence of provider permission, address accuracy, permit
verification, payment settlement or customer consent.

## Current source and setup links

- [Google Geocoding usage and billing](https://developers.google.com/maps/documentation/geocoding/usage-and-billing): review required billing, quota and policy controls for the separately approved integration.
- [Google Places Autocomplete](https://developers.google.com/maps/documentation/places/web-service/place-autocomplete): predictions, regional filters, session setup and attribution need a separate product decision.
- [Google Routes](https://developers.google.com/maps/documentation/routes): routes and route matrices are separate workloads; choose only after measuring dispatch needs.
- [Resend webhook event types](https://resend.com/docs/webhooks/event-types): API acceptance, delivery delay, delivery to a mail server and bounce are different events. Avoid open/click tracking by default.
- [PostHog JavaScript configuration](https://posthog.com/docs/libraries/js/config) and [pricing](https://posthog.com/pricing): manual events can use the existing consent owner; configuration must keep automatic products disabled.
- [Sentry Next.js options](https://docs.sentry.io/platforms/javascript/guides/nextjs/configuration/options/) and [pricing](https://sentry.io/pricing/): retain the error scrubber and zero trace/replay rates. Account plans and SDK defaults require checking at activation.
- [Vercel Observability](https://vercel.com/docs/observability), [Convex logs](https://docs.convex.dev/dashboard/deployments/logs), [Convex log streams](https://docs.convex.dev/production/integrations/log-streams) and [Trigger.dev runs](https://trigger.dev/docs/runs): use current platform coverage before adding another monitoring vendor.
