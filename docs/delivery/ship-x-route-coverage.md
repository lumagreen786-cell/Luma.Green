# Ship X route coverage — 11 November 2026

This inventory covers every `src/app/**/page.tsx` file in the working tree: **79 route entry files**. Dynamic routes can render multiple pages. A route count is not a count of roles, data states, languages or device layouts.

## Status meanings

- **Composition implemented:** the route, an imported composition component or a feature descendant has a current styling change. This is source evidence only.
- **Inherited shared shell/controls:** the route keeps its composition and receives the new canvas, fonts, navigation, buttons, fields, tabs or shared page sections. This does not claim a custom redesign of every child component.
- **Visual unverified:** this matrix does not yet include an inspected capture of the route's current applicable states. A parent delivery report can add exact capture evidence. Do not replace this with a blanket “verified” based on a build or unit tests.

Shared coverage: public SiteHeader/PageHeader; centered auth/join/household task surfaces; account navigation; app/admin navigation and page parts; light-only semantic tokens; shared controls. Photos remain source artwork. No sample transactions, weights, identities, permissions or provider success were added.
