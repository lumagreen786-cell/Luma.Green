# Platform code review — 25 October 2026

Status: fifteen confirmed defect groups repaired and locally verified. PR checks and production deployment are separate gates.

## Review scope

Reviewed web state and navigation, phone/profile boundaries, onboarding and workspace recovery, private uploads, household bookings, push delivery, stock and material movements, and Cashfree payment/hold transitions. The starting revision was `226f79e`, including the GST-only automatic activation changes. The review used separate domain reviewers and an independent pass over the combined repairs.

Native source remains on hold. This review does not certify native acceptance, successful paid provider calls, live payment processing, or production deployment. A code review and passing tests do not establish that the entire platform has no further defects.

## Portuguese/English report

The old middleware set `NEXT_LOCALE=pt` when Portuguese opened. A later English `/login` request with that cookie returned a 307 redirect to `/pt/login`. An explicit English request could write the cookie back. This establishes a cross-tab redirect fault. It does not establish that browser translation caused every reported crash.

The repaired browser test keeps Portuguese and English tabs open, switches the second tab between both languages, changes legacy cookie values, and reloads both. It checks the URL, document language, translated heading and page errors. Existing external-translator text-mutation tests also run. Browser translation remains available.

## Data and delivery

The schema changes are additive: `orgs.by_application`, `householdPhotos.by_storage`, and optional push binding version fields. No records are deleted or backfilled. Deploy the backend schema/functions before a frontend release that uses them. Existing live sending rows without a version use legacy version zero; a renewed binding has a later version.

Guide and Word updates remain deferred under AGENTS.md. The contact presentation and repaired controls need fresh guide captures when the owner requests that work.
